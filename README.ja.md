# oPlaits

[English](README.md) | **日本語**

（モジュール ID: `oplaits`）

Schwung / Ableton Move 用の Sound Generator です。中身は Mutable Instruments の
ユーロラック・モジュール **Plaits**（マクロオシレーター）の**非公式移植**で、
Emilie Gillet 氏が公開している公式ファームウェアの DSP ソースコードをそのまま
同梱して動かしています。音を作る部分を独自に作り直したり、簡略化したりはしていません。

- **公式 Plaits の全 24 エンジン**（ファームウェア 1.2 系で追加された 8 種を含む）を、
  実機と同じ番号・同じ並び順で選べます。
- 音源本体（エンジン選択、24 エンジン、内蔵ディケイ・エンベロープ、ローパスゲート、
  出力リミッター）は公式の `plaits::Voice` をそのまま呼び出しています。
  移植で置き換えたのは、ポット・CV 入力・トリガー入力・DAC といった
  **ハードウェアの部分だけ**です。
- 実機と同じ **47872.34 Hz・12 サンプルブロック**で DSP を動かし、44.1 kHz に
  リサンプルします（理由は「サンプルレートについて」）。
- テストで、本モジュールが鳴らす音声（OUT / AUX）が、公式の `plaits::Voice` を
  実機と同じ配線で直接駆動したときの出力と**1 サンプル単位で完全一致**することを
  全 24 エンジンで確認しています（「検証」）。

実機の Plaits から**残したもの・省いたもの・加えたもの**:

| | |
|---|---|
| 残したもの | 24 エンジンすべての音作り、HARMONICS / TIMBRE / MORPH、3 つのアッテヌバーター（FM / TIMBRE / MORPH）と内蔵エンベロープによるモジュレーション、LPG（DECAY / LPG COLOUR）、OUT / AUX の 2 出力、トリガーの約 1 ms 遅延などファームウェアの細かな挙動 |
| 省いたもの | V/OCT 以外の CV 入力（FM・HARMONICS・TIMBRE・MORPH・MODEL）、ユーザーデータ（独自ウェーブテーブルや DX7 バンク）の音声転送、キャリブレーション、LED・ボタンの操作 |
| 加えたもの | MIDI での演奏（ノート = V/OCT + TRIG、ベロシティ = LEVEL）、OUT/AUX のミックス、音量、Move のトランスポートに同期した 16 分音符の自動トリガー、16 ステップのトリガーパッド、ノブの動きの記録、メロディの自動生成（RANDOM）、プリセットパッド、使うエンジンの絞り込み |

**シーケンサーを内蔵しています。** Move で Play を押すと、クリップや MIDI ノートを
用意しなくても、テンポに合わせて 16 分音符ごとに自動で鳴り始めます（8 または
16 ステップのループ）。Move のトラックからの MIDI ノートでも普通に演奏できます。

各エンジンでの HARMONICS / TIMBRE / MORPH の意味は実機と同じです（Plaits の公式
マニュアルを参照してください）。

**エンジンごとの、実機どおりの挙動（不具合ではありません）**

- **CHIP（7）**: トリガーで鳴らすと、このエンジンは LPG を使わず、自分のエンベロープの
  形を **TIMB>（TIMBRE アッテヌバーター）** から取ります。TIMB> が中央（0）のときは
  減衰しないので、ノートを離しても鳴り続けます。TIMB> を回すと減衰するようになります。
- **6OP1〜3（2〜4）**: 音の長さは DX7 パッチ自身のエンベロープで決まり、LPG は使いません。
  ノートを離してから長く鳴るパッチもあります。
- **KICK・SNARE・HIHAT・STRNG・MODAL**: 自分でエンベロープを持つので LPG を通りません。
  長さはエンジン自身のパラメーター（MORPH など）で決まります。
- **VA（8）**: HARMONICS は 2 つ目のオシレーターのデチューンで、中央（50 %）がユニゾン、
  0 % で 2 オクターブ下になります。

## ビルド方法

このリポジトリ単体でビルドできます。Plaits の公式ソースは `src/plaits/mi/` に、
Schwung のプラグイン API ヘッダー（`plugin_api_v1.h`、MIT）は `third_party/schwung/` に
同梱しています。

```bash
scripts/build.sh arm64
```

→ `dist/oplaits-module.tar.gz`（Move 用 AArch64 `dsp.so` + UI + ライセンス）

必要なもの: `aarch64-linux-gnu-g++`、`python3`。ビルド時に
`scripts/check_abi.py` が「AArch64 である」「glibc 2.34 以下」「libstdc++ 非依存」
「公開シンボルは `move_plugin_init_v2` のみ」を検査し、満たさなければ失敗します。

テスト一式（公式ソースとの照合、ネイティブ ASan/UBSan のエンジンテスト、実 `dsp.so` の
dlopen スモーク、UI テスト、最後に arm64 ビルド）と、パッチの影響の確認:

```bash
scripts/test.sh
scripts/compare_upstream.sh
```

UI テストには Node.js と、Schwung 本体のチェックアウト（ページエンジンと描画ハーネスを
使うため）が必要です。このリポジトリと同じ階層の `../schwung`、または
`SCHWUNG_ROOT=/path/to/schwung` を使います。見つからなければ UI テストだけ飛ばします
（WSL では Windows 側の `node.exe` でも可）。

Move 上での CPU 測定（SSH が必要。Move の `/data/UserData/schwung/` に一時的に
ベンチマークを置いて実行し、終わったら消します）:

```bash
scripts/bench_move.sh ableton@move.local
```

## Move へのインストール

Schwung Manager（`http://<Move の IP>:7700`）経由でアップロードします:

```bash
scripts/install.py http://move.local:7700                                   # dist/ のもの
scripts/install.py http://move.local:7700 --package oplaits-module.tar.gz   # ダウンロードしたもの
```

（`--check` を付けると接続確認のみ）。インストール後、チェーンのスロットで
Synth に **oPlaits** を選びます。

**更新したときは Move を再起動してください。** 読み込み済みの古い `dsp.so` が
プロセスに残るため、スロットを選び直すだけでは新しい版になりません。

## 使い方（はじめての操作）

基本の流れは「スロットに入れる → 再生する → ノブで音を作る → パッドでパターンを作る
→ REC でノブの動きを記録する」です。

### 1. 音を出す

1. Schwung の画面（Shift+Vol+Track、またはトラックボタン長押し）でスロットを開き、
   Synth に **oPlaits** を選びます。
2. スロットの Synth（oPlaits）を開くと、oPlaits の画面になります。
3. Move の **Play** を押します。oPlaits は**トランスポートに合わせて 16 分音符ごとに
   自動で鳴ります**（クリップや MIDI ノートは不要）。停止中は鳴りません。
   Move のトラックからの MIDI ノートでも演奏できます。

### 2. 音色を作る（メインページ）

| ノブ 1 | ノブ 2 | ノブ 3 | ノブ 4 |
|---|---|---|---|
| VOLUME | HARMONICS | TIMBRE | DECAY |
| **ノブ 5** | **ノブ 6** | **ノブ 7** | **ノブ 8** |
| COLOR | MORPH | ENGINE（24 種） | PITCH |

- **ENGINE** で音源の種類、**HARMONICS / TIMBRE / MORPH** で音色を作ります
  （実機の 3 つの大きなポット）。
- **DECAY** と **COLOR** は実機のシフト機能（LPG DECAY と LPG COLOUR）です。
  DECAY で音の長さ、COLOR で LPG の性格（0 % = VCA 寄り、100 % = ローパスフィルター寄り）。
- **PITCH** は自動トリガーの音程で、スケール上の音を選びます（スケールは Scale ページ）。
- **よく使うエンジンだけに絞る**: ENGINES パッド（RANDOM の左隣）で一覧を開き、
  使うエンジンだけを ON にできます。すると ENGINE ノブは ON のエンジンだけを選ぶように
  なります（下の「使うエンジンを選ぶ（ENGINES 一覧）」）。
- **ジョグを回す**と Plaits（アッテヌバーター・AUX・音程・入力の設定）→ Scale
  （ROOT・SCALE・STEPS）→ My Presets（プリセット）→ Module のページに移ります。

### 3. パターンを作る（パッド）

画面を開いている間、パッドは oPlaits 専用になります（Move 純正には届きません）。

```
                         ENGINES RANDOM  REC   ← 一番上の段の右 3 つ
 P1  P2  P3  P4  P5  P6  P7  P8                ← 上から 2 段目（プリセット）
  9  10  11  12  13  14  15  16                ← 下から 2 段目
  1   2   3   4   5   6   7   8                ← 一番下の段
```

- **下 2 段**を押すと、そのステップの発音を ON（明るい）/ OFF（暗い）で切り替えます。
  白く光っているのが今鳴っているステップ。8 ステップのときは下から 2 段目は消灯です
  （16 ステップは Scale ページの STEPS で）。
- **RANDOM** を押すと、新しいメロディが PITCH に書き込まれます（下の「RANDOM」）。
- **ENGINES** を押すと、ENGINE ノブで選べるエンジンの ON/OFF 一覧が開きます。
- **上から 2 段目**の 8 個はプリセットです（下の「5. プリセットに保存する・呼び出す」）。

### 4. ノブの動きを記録する（REC）

1. **REC**（一番右上のパッド）を押して ON にします（真っ赤に光る。OFF は薄い赤）。
2. Move を再生した状態で、記録したいノブに**触れたまま回します**。
   触れている間だけ、ループの各ステップにその値が記録されます。指を離すと記録終了。
3. 記録されたノブは、以後ループのたびにその動きを再生します。
   ノブの値自体は書き換わらず、記録を消すと元の値に戻ります。
4. 消すとき: **Shift を押しながらノブに触れる**とそのノブの記録を消去。
   **Shift + ノブ 1（VOLUME）に触れる**と全部消去。
5. 記録が終わったら REC をもう一度押して OFF にすると、うっかり触っても記録されません。

記録できるのは HARMONICS・TIMBRE・MORPH・DECAY・COLOR・PITCH・FM>・TIMB>・MORPH>・
AUX です（VOLUME・ENGINE・COARSE・FINE・VELO・TRIG と Scale ページは記録しません）。

### 5. プリセットに保存する・呼び出す

**パッドで（すばやく 8 つ）:** 上から 2 段目の 8 個のパッドがプリセット 1〜8 です。

- **保存**: Shift を押しながらパッドをタップ。今の状態をまるごと覚えます。
- **呼び出し**: パッドをタップ。再生中でもすぐに切り替わります（エンジンも切り替わります）。
- 色: 消灯 = 空き、薄い黄色 = 保存済み、白 = 最後に呼び出した（保存した）もの。
  空きのパッドをタップすると画面に `EMPTY` と出るだけで、何も変わりません。
- 覚えるのは、ENGINE を含むすべてのノブの値・記録したノブの動き・RANDOM で作った
  メロディ・ステップの ON/OFF・ROOT / SCALE / STEPS です（REC の ON/OFF と ENGINES
  一覧は含みません）。
- 8 つのプリセットはセットとは関係なく `/data/UserData/schwung/oplaits/presets.json` に
  保存され、どのセット・どのスロットの oPlaits からでも同じ 8 つが使えます。
  他のモジュールのプリセットとは別のファイルなので、上書きし合うことはありません。
  再インストールしても消えません。

**名前を付けて（数の制限なし）:** ジョグを回して最後のほうのページ **My Presets** に行きます。

- **Save As**: 今の状態に名前を付けて保存（キーボードが出ます）。
- **Preset**（一番上の行）: クリックするとプリセット一覧が開き、選んだものを読み込みます。
- **Save**: 読み込み中のプリセットに上書き保存。**Delete**: 読み込み中のプリセットを削除。

こちらは Schwung 共通のプリセット機能で、モジュール ID（`oplaits`）ごとのフォルダー
（`/data/UserData/schwung/presets/oplaits/`）に保存されます。

### 6. 終わるとき

**Back** で画面を閉じます。パッドは Move に戻ります。音色・記録・ステップの ON/OFF は
セット（スロットのオートセーブ）やプリセットに保存されます。

## 操作方法（詳細）

画面とノブは Schwung 標準のノブ画面（8 つのノブがページごとに並ぶ形）と同じ見た目・操作で、
それにノブへのタッチ（記録用）とパッドの操作を加えています。

| 操作 | 動作 |
|---|---|
| ノブ 1–8 | 現在ページのパラメーター（下のページ表） |
| ノブにタッチ（REC ON・再生中） | そのノブの動きを**モーション記録** |
| Shift + ノブにタッチ | そのノブの記録を消す。VOLUME（ノブ 1）なら**全部**消す |
| ジョグ回転 / クリック | ページ切替・項目選択（Schwung 標準グリッドと同じ） |
| Back | 画面を閉じる（パッドは Move に戻る） |

ページ:

| ページ | ノブ 1–8 |
|---|---|
| メイン | VOLUME・HARMONICS・TIMBRE・DECAY・COLOR・MORPH・ENGINE・PITCH |
| Plaits | FM>・TIMB>・MORPH>・AUX・COARSE・FINE・VELO・TRIG |
| Scale | ROOT・SCALE・STEPS |
| My Presets | プリセットの呼び出し・保存・削除（Schwung 共通） |
| Module | モジュールの入れ替え・ヘルプ（Schwung 共通） |

ヘッダーには今のエンジン名、ループの位置、REC ON 中は `ARM`、記録中は `REC` が出ます。
PITCH に触れている間は音名（例 `PITCH Eb3`）。記録のあるノブは Schwung の
「モジュレーション中」の表示（再生中の値が動く）になります。

ステップ式のノブ（ENGINE・PITCH・COARSE など）は加速せず、数ディテントで 1 段ずつ進みます。
連続値のノブ（HARMONICS など）は速く回すと加速します（Schwung 標準のノブと同じ）。

## パッド

**この画面を開いている間、パッドは oPlaits が占有します**（`host_pad_block`）。
Move 純正の音源・シーケンサーにはパッド操作が届きません。画面を閉じるとパッドは
Move に戻り、色も元に戻ります（Schwung の仕様で、占有できるのは画面表示中だけ）。

| パッド | 動作 |
|---|---|
| **REC**（右上） | モーション記録の ON/OFF。**ON = 真っ赤、OFF = 薄い赤** |
| **RANDOM**（その左隣） | 新しいメロディを作り、PITCH の各ステップに書き込む |
| ENGINES（さらに左） | ENGINES 一覧（使うエンジンの設定）を開く／閉じる |
| 上から 2 段目（8 個） | プリセット 1–8。タップで呼び出し、Shift + タップで保存 |
| 下 2 段（16 個） | 各ステップのトリガー ON/OFF。ON = 明るい、OFF = 暗い、再生中のステップ = 白。8 ステップ時は上の段（9–16）は消灯 |

- 再生は **Move のトランスポートに同期して 16 分音符ごとに自動で発音**します
  （Play で開始、停止中は鳴りません。ステップの頭は小節頭にそろいます）。
  各ステップの頭で Plaits の TRIG にトリガーが入ります。トリガー OFF のステップでは
  ゲートを下ろし、音は LPG（またはエンジン自身のエンベロープ）で自然に減衰します。
- ループの長さは Scale ページの **STEPS**（8 / 16、既定 8）。
- Move のトラックから来る MIDI ノート（クリップや、画面を閉じているときのパッド）も
  oPlaits を鳴らします。

### モーション記録

- REC を ON にして Move を再生し、**ノブに触れている間**、そのノブの動きが
  ループに記録されます（16 分音符 1 つにつき 8 点、12 ビット）。指を離すと終了。
- 連続値のノブは点と点の間をなめらかにつなぎ、PITCH は点の値をそのまま保ちます。
- 再生はノブの値を書き換えません（記録が優先されるだけ）。Shift + タッチで消すと
  ノブの値に戻ります。
- 停止中は記録も再生もせず、ノブの値で鳴ります。

### PITCH（ノブ 8）

- **PITCH は最初からスケール上の音**です。ノブ 8 は Scale ページの ROOT + SCALE の
  音だけを C1〜C6（5 オクターブ）の範囲で選びます（後からクオンタイズするのではなく、
  ノブ自体がスケールの音階で動きます）。既定は C フリジアンの C3。
- ROOT / SCALE を変えると、PITCH と記録済みの PITCH は新しいスケールの最寄りの音に移ります。
- SCALE: Phrygian（既定）・Minor・Dorian・Major・Mixolyd・Lydian・Locrian・HarmMin・
  PhrygDom・MinPent・In・Chromatic。
- PITCH は自動トリガーの音程です。MIDI ノートで弾くときは、そのノートの音程で鳴ります。

### RANDOM（メロディの自動生成）

RANDOM は、**`patterns/` に入っている MIDI ファイル（元フレーズ）を元に、毎回少し
違うメロディを作って PITCH に書き込む**ボタンです。最初は 6 つの元フレーズが入っています。

**押したときに起きること**

1. 元フレーズの中から 1 つをランダムに選びます（直前と同じものは選ばれにくくなっています）。
2. その元フレーズの音の並びを「変化量 50 %」で変化させます。おおよそ半分の音が、
   スケール上で隣の音に動く・オクターブ跳ぶ・前の音を繰り返す、などの形で変わり、
   残りは元フレーズのままです。毎回違う結果になり、直前のメロディと同じにはなりません。
3. 休符は作りません。元フレーズの休符の位置も音で埋め、全ステップに音程が入ります。
4. できたメロディを PITCH の記録として、ループの各ステップに書き込みます。
   - STEPS が 8 なら 8 ステップ、16 なら 16 ステップ（8 ステップの変化を 2 つ続けたもの）。
   - それまでの PITCH の記録は、STEPS の分だけ上書きされます。
   - 鳴るかどうかは下 2 段のパッドで決まります。RANDOM はステップの ON/OFF を変えません。

**音域と音階**

- 書き込まれる音は、すべて Scale ページで設定したスケール（ROOT・SCALE）の音です。
- 音域は**ノブ 8（PITCH）の音を基準に、5 度下から 1 オクターブ半上まで**（-7 〜 +17 半音、
  C1〜C6 の中）。範囲を出る音はオクターブ単位で折り返して収めます。押す前にノブ 8 で
  全体の高さを決めておけます。

**取り消す・作り直す**

- もう一度押すと、別のメロディで書き直します。
- **Shift + ノブ 8 にタッチ**で PITCH の記録を消すと、ノブ 8 の音だけに戻ります。
- REC を ON にしてノブ 8 に触れながら回せば、一部のステップだけ手で書き換えられます。

#### 元フレーズを入れ替える

元フレーズの MIDI はビルド時に `dsp.so` に埋め込まれます（Move 上でファイルを読みに
行くことはしません）。入れ替えたら**ビルドし直して、インストールし直す**必要があります。

1. 使いたい MIDI ファイル（Standard MIDI File、`.mid`）を `patterns/` に置きます。
2. `patterns/patterns.txt` に、使うファイルを 1 行に 1 つずつ書きます（1〜16 個）。
   行の順番が元フレーズの番号です。`#` から後はコメントです。

   ```
   my_riff.mid          # ファイルの先頭から 8 ステップ
   long_phrase.mid 16   # 17 ステップ目から 8 ステップ（2 列目は開始位置）
   ```

   `patterns.txt` を消すと、`patterns/` の `.mid` をすべて名前順に使います。
3. ビルドしてインストールし、Move を再起動します。

MIDI ファイルのどこが使われるか:

- 各ファイルの**開始位置から 16 分音符 8 個分**だけを使います。
- 使うのは**音程と並び順だけ**です。ベロシティや音の長さは使いません。
- ノートの位置は一番近い 16 分音符に寄せます。同じステップに複数の音があるときは、
  一番強い（同じなら先の）音を 1 つだけ使います。全トラック・全チャンネルをまとめて読みます。
- 元フレーズは、読み込むときに一度 **C フリジアン**の音に寄せてから変化させ、
  最後に設定中の ROOT・SCALE に合わせ直します。C を主音にしたフリジアンで書くと
  いちばん元の形が残ります。
- 開始位置から 8 ステップの中にノートが 1 つも無いファイルは使われません。
  ファイル名は 31 バイトまで、ノートは 1 ファイル 256 個まで読みます。

## 使うエンジンを選ぶ（ENGINES 一覧）

24 エンジンのうち、ENGINE ノブで選べるものを決められます。

1. **ENGINES パッド**（RANDOM の左隣）を押す → 一覧が開きます（右端の `<` が今鳴っているエンジン）。
2. ジョグを回してカーソル移動（端で止まります）、ジョグクリックで **ON / OFF**（■ = ON、□ = OFF）。
3. 先頭の **ALL ON** ですべて ON、**ALL OFF** で今鳴っているエンジン以外をすべて OFF。
4. **Back** か ENGINES パッドで一覧を閉じます。

- 変更はすぐ保存されます（`/data/UserData/schwung/oplaits/settings.json`）。
  全スロットの oPlaits 共通で、再インストールでも消えません。プリセットには含まれません。
- ENGINE ノブは ON のエンジンだけを順に選び、両端で止まります。
- 最低 1 つは ON のまま残ります（「ONE MUST STAY ON」）。
- プリセットが OFF のエンジンを使っていても、そのエンジンで鳴ります（一覧の設定は
  ノブで選べる範囲だけを決めます）。

アッテヌバーターは内蔵ディケイ・エンベロープの量です。TRIG = ON（トリガーが挿さった状態）
のときに働き、エンベロープの長さは DECAY で決まります（実機と同じ）。

### AUX（OUT / AUX のミックス）

Plaits には OUT と AUX の 2 つの出力があり、エンジンごとに AUX は別の音
（もう一方の波形、サブオシレーター、別の合成方式など）を出します。

- 0 % = OUT だけ、100 % = AUX だけ、50 % = 両方を等しく。
- 混ぜ方は**等パワー**（OUT × cos、AUX × sin）です。50 % ではそれぞれ -3 dB で足すので、
  互いに無関係な 2 つの音なら全体の音量はほぼ変わりません。
- 値を変えると約 2.5 ms でなめらかに移り、プツッという音は出ません。

### VELO と TRIG（MIDI ノートが何をするか）

MIDI ノートは、実機に次のようにケーブルを挿したのと同じ扱いになります。

- **ノートの音程 → V/OCT 入力**（ピッチベンドは ±2 半音を加算）。
- **ノートを押している間 → TRIG 入力が High**（TRIG = ON のとき）。押した瞬間が
  トリガーです。前のノートを押したまま新しいノートを押したとき（レガート）や、
  同じノートが続けて来たときも、ゲートを 1 ブロック（0.25 ms）だけ下げてから
  上げるので、**毎回トリガーが入ります**。
  後から押したノートを離すと、押したままの前のノートの音程に戻ります（再トリガーなし）。
- **VELO = OFF**（既定）: LEVEL 入力は何も挿していない扱いです。トリガーが LPG を
  「ピング」して、DECAY の長さで減衰します（実機で TRIG だけを挿したときの音）。
  ベロシティは音に影響しません（アクセントは実機と同じ 0.8 固定）。
- **VELO = ON**: LEVEL 入力に、押している間だけノートのベロシティを入れた扱いです。
  LPG はこの電圧に従って開き（押している間は持続し、離すと DECAY に応じて閉じる）、
  ベロシティはアクセント（ドラム系エンジンの強さなど）にもなります。
- **TRIG = OFF**: TRIG 入力を挿していない扱いです。エンジンはトリガーなしで鳴り続けます。
  VELO = ON と組み合わせると「ノートを押している間だけ鳴るシンセ」、VELO = OFF だと
  実機のフリーランと同じ**鳴りっぱなし**になります（最初のノートが来るまでは無音。
  止めるには CC 120 を送るか TRIG を ON に戻してください）。
- 同時発音は 1 音です（実機の Plaits と同じモノフォニック。後から押したノートが優先）。
  Plaits はもともと 1 音の音源なので、ポリフォニックにはしていません。

## MIDI

| メッセージ | 動作 |
|---|---|
| ノートオン / オフ | 上記のとおり。ベロシティ 0 のノートオンはノートオフ |
| ピッチベンド | ±2 半音 |
| CC 123（All Notes Off） | 押しているノートをすべて離す（音は自然に減衰） |
| CC 120（All Sound Off） | すべてのノートを離し、3 ms で無音にする（次のノートまで） |
| MIDI クロック | ホストのトランスポート位置が取れないときだけ、自動トリガーの代わりの時計として使う |

## 状態保存

スロットの状態（セットのオートセーブ）とプリセットには、すべてのパラメーター
（ENGINE を含む）、記録したノブの動き、ステップの ON/OFF がテキスト（JSON）で入ります。
読み込むと、エンジンも含めてすべてが元どおりになります（テストで、保存したものを
別のインスタンスに読み込むと同じ音が出ることを確認しています）。知らないキーは無視し、
足りないキーはその値のまま、範囲外の値は範囲内に収めます。

## サンプルレートについて

Plaits の DSP には「48 kHz」と書かれていますが、実機の I2S クロックは
72 MHz ÷ 47 ÷ 32 = **47872.34 Hz** で、音程の基準値（`a0`）はこの実際のレートに
合わせて計算されています（`plaits/dsp/dsp.h` の `kCorrectedSampleRate`）。
ディケイや LPG、フィルター、トリガー遅延などの時間もすべて、このレートでのサンプル数・
ブロック数で決まっています。

定数を 44.1 kHz に書き換えると、音程だけ直しても時間の特性がすべて狂います。
そこで本モジュールは DSP を**実機と同じ 47872.34 Hz・12 サンプルブロック**で動かし、
その出力を 44.1 kHz にリサンプルします。44100 ÷ 47872.34 はちょうど 6909/7500 なので、
出力サンプルの位置は正確に計算できます。フィルターは 64 タップのカイザー窓付き sinc
（256 位相を線形補間）で、20 kHz まで平坦（±0.05 dB 以内）、23.7 kHz で -70 dB です。
遅延は約 0.7 ms です。

この結果、**A4 は 440.000 Hz**（テストでの実測）で、エンベロープの長さもエンジン内部の
時間も実機どおりです。

## CPU とメモリ

- オーディオスレッドでのメモリ確保・ファイルアクセス・ロックはありません。
  インスタンスは最大 6 個の静的プールから取り、それぞれが自分の `plaits::Voice` と、
  実機と同じ 16 KB のエンジン用共有 RAM を持ちます（1 インスタンス約 31 KB）。
- 24 エンジンはすべて 16 KB に収まります（一番大きい PARTI がちょうど 16384 バイト）。
- エンジン切替は実機と同じく、そのエンジンのデータ読み込みとリセットだけです。
- **Move 実機での測定**（`scripts/bench_move.sh`、2026-10-13、host 1.7.3）: 1 ブロック
  （128 サンプル = 2902 µs）あたりの平均は全エンジンで 68〜135 µs、最も重い ADDIT・FM・
  VAVCF でも**約 4.6 %**。エンジン切替を含むブロックの最大は 0.8 ms、インスタンス作成は
  0.1〜0.4 ms。ベンチは通常優先度で Move 本体と並んで動くため、ブロック単位の最大値
  （0.5〜2.5 ms）はエンジンの重さと関係なく一律にばらつき、OS による割り込みの分を含みます。
- **実際のスロットでの測定**（Schwung の CPU ページ、Slot 3、他に 2 つの音源と 3 つの
  Master FX が動いている状態）: 平均 146 µs（フレームの 5.7 %）、最大 190 µs。

## 検証

`scripts/test.sh`（ホスト PC 上）で確認していること:

- **公式との照合**: 同梱ソースが、記録したコミットの公式ソース + `patches/` と
  1 バイトも違わないこと（毎回ダウンロードして比較）。
- **出力の一致**: 全 24 エンジン × 3 設定（標準 / VELO ON + アッテヌバーター /
  TRIG OFF + 移調）で、ノート・レガートの再トリガー・リリース・ノブの掃引・
  演奏中のエンジン切替を含む演奏を、本モジュール経由と、公式 `plaits::Voice` を実機と
  同じ配線で直接駆動したものとで鳴らし、OUT と AUX の全サンプルが一致すること。
- 音程（A4 = 440.000 Hz、COARSE・FINE・ピッチベンド）、リサンプラーの周波数特性。
- 全エンジンが有限で範囲内の音を出し、ノートの後に止まること。
- AUX の等パワーミックス、VELO、レガートの再トリガー、TRIG OFF、CC 120 / 123。
- 1 分間ぶんのランダムなノート・ノブ・エンジン切替（AddressSanitizer /
  UndefinedBehaviorSanitizer 付き）でクラッシュも異常値もないこと。
- 自動トリガー、パッド、モーション記録、RANDOM、状態保存、ノートの残りがないこと。
- 実際の `dsp.so` を Schwung と同じ API で読み込んでのスモークテスト、UI テスト。

`scripts/compare_upstream.sh` は、**何も手を加えていない公式ソース**と同梱ソースで
同じ演奏（全エンジン、約 212 万フレーム）を鳴らして比べ、パッチ 0001・0002 は完全一致、
0003・0004 による違いは公式コードが自分の持ち物でないメモリを読む箇所だけであることを
確認します（現在の演奏では、違いは 6-op への切替直後の 60 フレームだけ）。

### 公式ソースに当てたパッチ（`patches/`）

テスト中に、公式コード自体の範囲外アクセスが 4 つ見つかりました。どれも最小限の修正で、
ソース中に `oPlaits patch` のコメントを付けています。

| パッチ | 内容 | 音への影響 |
|---|---|---|
| 0001 | 6-op FM: ベロシティ（アクセント）がちょうど 1.0 のとき、`lut_cube_root[17]`（表の 1 つ先）を読む | なし（読んだ値には 0 が掛かる。同じ値を範囲外読みなしで返す） |
| 0002 | SPEAK: 補間なしで最後の音素・単語フレームを鳴らすとき、表の 1 フレーム先を読む | なし（同上） |
| 0003 | WTERR: AUX 出力でサイン関数に負の位相を渡し、サイン表の**手前**（最大 153 個前）を読む | 公式コードではその瞬間、表の手前にある無関係なデータが音になる。負の位相を正しく折り返して計算する |
| 0004 | 6-op FM: エンジンを切り替えた直後の 1 ブロック、共有 RAM 上の加算バッファを初期化せずに読む | 公式コードでは前のエンジンの残りが 12 サンプルだけ混ざる。実機（32 ビット）ではほぼ無害な値だが、64 ビットの Move では WTBL の後などにポインター値が巨大な値・NaN として出る恐れがあるため、切替時に 0 にする |

もう 1 つ、公式の WTBL エンジンは確保した数（64 個）より多いポインター（256 個）を
共有 RAM に書き込みますが、書き込み先は 16 KB の共有 RAM の内側に収まり、
他のエンジンは切替時に必要なデータを読み直すため、実害はありません（実機でも同じ）。
これは変更していません（0004 はこの書き込みの残りが 6-op で音に出るのを防ぐものです）。

## レベルとヘッドルーム

Plaits のエンジンは実機どおりの音量で出てきます（VOLUME 100 % のテストで、ピークは
エンジンによって約 -17〜-3 dBFS）。VOLUME の既定 50 % ではさらに -6 dB です。
最終段に安全用のソフトリミッター（-0.9 dBFS から先をなめらかに丸める）があり、
VOLUME 100 % で大きな音を鳴らしてもハードクリップしません。既定の音量では
リミッターにかかりません。
